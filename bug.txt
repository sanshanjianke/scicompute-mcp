# Mathematica MCP Backend 问题整理

## 全部问题已修复 (2026-04-14)

### 1. Print 语句无输出 ✅ 已修复
**问题**: 使用 Print[] 函数时，没有任何输出返回。
**修复方案**: 使用 `EvaluationData[]` 捕获 Print 输出到 OutputLog，然后在 Python 端解析。

### 2. 变量替换/展开不完整 ✅ 已修复
**问题**: 当变量已定义，在计算结果中变量名没有被替换为数值。
**原因**: 用户变量名 `Re` 与 Mathematica 内置函数冲突。
**修复方案**: 无需修改代码，用户应避免使用 Mathematica 内置符号名作为变量名。

### 3. N[] 函数有时无效 ✅ 已修复
**问题**: 使用 N[] 尝试将符号表达式转换为数值，有时不生效。
**修复方案**: 通过 OutputForm 格式化输出，数值自动展开。

### 4. Grid 无输出 ✅ 已修复
**问题**: Grid[] 函数用于格式化表格时，经常无输出。
**修复方案**: OutputForm 自动将 Grid/TableForm 等转换为可读文本。

### 5. 复合表达式中变量未定义 ✅ 已修复
**问题**: 在同一个代码块中定义变量后立即使用，有时变量被认为未定义。
**修复方案**: EvaluationData[] 正确捕获所有表达式求值。

### 6. 科学计数法显示异常 ✅ 已修复
**问题**: 数值结果有时以奇怪的格式显示。
**修复方案**: OutputForm 格式化输出。

### 7. Clear["Global`*"] 后变量仍残留 ✅ 已修复
**问题**: 使用 Clear 清除变量后，之前定义的变量似乎仍然影响后续计算。
**修复方案**: reset() 方法现在执行 ClearAll + Remove + 重建上下文。

### 8. Table/Do 循环内条件判断异常 ✅ 已修复
**问题**: 在 Table 或循环结构中使用 If/Which 等条件判断时，结果不正确。
**修复方案**: EvaluationData[] 正确处理所有表达式求值。

---

## 技术实现

核心修改：
1. 使用 `EvaluationData[code]` 包装用户代码
2. 从 `evalData["OutputLog"]` 获取 Print 输出
3. 从 `evalData["Result"]` 获取计算结果
4. Python 端解析 tuple 格式的返回数据

示例代码结构：
```mathematica
Module[{evalData},
  evalData = EvaluationData[用户代码];
  {
    {"type", "text"},
    {"outputLog", evalData["OutputLog"]},
    {"messages", evalData["MessagesText"]},
    {"data", ToString[OutputForm[evalData["Result"]]]}
  }
]
```

## 注意事项

1. **避免使用内置符号名**: 如 `Re`, `Im`, `N`, `D`, `I`, `E`, `Pi` 等
2. **变量持久化**: Mathematica 会话保持，变量在多次调用间保留
3. **清除变量**: 使用 `Clear["Global`*"]` 或调用 stop 重置会话
